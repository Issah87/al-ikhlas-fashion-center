# Al-Ikhlas Fashion Center 🇬🇭

> Ghana's Premier Bespoke Abaya, Khimar & Boubou Fashion House  
> Located at Oforikrom, Accra Town Behind Central Mosque, Kumasi, Ghana

Al-Ikhlas Fashion Center is a modern modest fashion e-commerce platform and bespoke tailoring management system tailored specifically for the Ghanaian market.

---

## 🌟 Key Features

### 1. Jumia-Style Modest Fashion Catalog
- Full collection of bespoke modest wear:
  - Straight Abayas & Dresses
  - Gathered Boubous & Tiers
  - Pleated Luxury & Maxis
  - Capelet & Two-Piece Sets
  - Classic & Coat Abayas
- Interactive color swatches with dynamic garment preview
- Height and length sizing guide (50" to 60" / petite to extra tall)
- Quick search and instant category filter drawer

### 2. Mandatory Mobile Money (MoMo) Payment Flow
- **Official Recipient MoMo Number**: `0541376807` (Al-Ikhlas Fashion Center / Issah)
- **Supported Networks**: MTN Mobile Money (`*170#`), Telecel Cash (`*110#`), AT Money
- **Pre-Order Payment Verification**: Customers complete payment on their phone and provide their paying number, network, and **MoMo Transaction ID / Reference** from their SMS receipt before orders can be submitted.

### 3. Customer Account Management
- **Account-First Policy**: Customers create an account before logging in and placing orders to ensure order tracking and bespoke measurement history.
- **My Ordered Dresses**: Live customer portal tracking order status (`Order Confirmed`, `Fabric Sourced`, `Sewing in Progress`, `Ready for Pickup / Dispatch`, `Delivered`).
- Real-time on-website messaging between the customer and the boutique dressmaker.

### 4. Atelier Owner & Admin Management Portal
- Comprehensive view of every customer order placed across Ghana.
- Mobile Money verification terminal to inspect incoming transfers to `0541376807` and verify matching Transaction IDs.
- One-click payment verification that automatically updates the customer's order status and sends a confirmation message.
- Status updater, delivery logistics tracking (workshop pickup, Accra/Kumasi dispatch, VIP/STC parcel bus).
- Customer messaging thread and order sheet export.

## 🚀 Tech Stack

- **Framework**: React 19 + TypeScript
- **Styling**: Tailwind CSS
- **Bundler & Dev Server**: Vite
- **Icons**: Lucide React
- **Typography**: Cormorant Garamond & Plus Jakarta Sans

---

## 📦 Getting Started

### Installation
```bash
npm install
```

### Run Locally
```bash
npm run dev
```
The app will be available at `http://localhost:3000`.

### Build for Production
```bash
npm run build
```
